# Flagship: RLOO on 7B @32k through an evicting cache

*The first "dense cannot do this" training result. Qwen2.5-7B-Instruct,
HELMET @32k (prompts ~27-32k tokens), RLOO + em_f1 reward,
`h2o-torch-quantized8@8192` (retaining ~25-30% of the prompt), 200 steps
(group 4 x 2 accumulated prompts), paged 8-bit AdamW, lr 5e-6, single L40S
48GB per run. Dense-attention GRPO OOMs at 24k on this hardware
(`docs/GRPO_CONTEXT_SCALING.md`), so every run below trains in a regime
where full attention cannot run at all. Eval: n=50 question-diverse
records, seeded 32k canonical splits.*

## Cross-eval matrix (EM / F1)

**nq @32k** (base: 0.80 / 0.179 dense-eval; 0.52 / 0.102 through-cache):

| checkpoint | dense-eval | through-cache |
|---|---:|---:|
| RLOO s0 | 0.88 / 0.307 | 0.68 / 0.171 |
| RLOO s1 | 0.68 / 0.258 | 0.56 / 0.137 |

**hotpot_qa @32k** (base: 0.40 / 0.109; 0.24 / 0.073):

| checkpoint | dense-eval | through-cache |
|---|---:|---:|
| RLOO s0 | 0.42 / 0.101 | 0.36 / 0.094 |
| RLOO s1 | 0.50 / 0.584 | 0.38 / 0.455 |

## Claims (in decreasing order of confidence)

1. **Training through the actively evicting cache produces real gains in a
   regime where dense training cannot run.** 4/4 arms improve under
   through-cache eval: +16/+4 (nq), +12/+14 (hotpot) EM. Sign-consistent
   across tasks and seeds.
2. **Training shrinks the eviction penalty.** The dense-vs-cached gap on
   the same checkpoint: nq 28pp (base) -> 20/12pp (trained); hotpot 16pp
   -> 6/12pp. Consistent with the 0.5B campaign finding at 8k.
3. **Dense inference still beats cached inference on every checkpoint.**
   No claim that sparse attention outperforms dense attention is made or
   supported; the eviction information loss (A1/A2) survives training.
4. Dense-eval improvements are **mixed across seeds on nq** (+8 / -12) and
   should not be quoted without the style caveat below.

## Verification performed

- Base rows in each cross-eval reproduce the standalone probes *exactly*
  (0.80/0.52 nq, 0.40/0.24 hotpot) -- deterministic paired evaluation, no
  drift between runs.
- Learning curves are gradual (hotpot through-cache eval on held-out
  records: 0.000 -> 0.375 -> 0.375/0.500 at steps 0/100/200), not
  single-step jumps.
- Generation inspection (hotpot s1, the arm with the largest F1 shift):
  training compressed verbose scaffolded answers ("Based on the information
  provided in the document titled...") to terse spans ("Ang Lee"). Correct
  content, no degenerate outputs. This style shift legitimately raises
  rouge-F1 (verbosity is penalized) and is safe for hotpot EM
  (self-contained targets); it is the known risk factor for **nq** EM
  (targets with leading prepositions), which is why the nq dense-eval
  numbers carry a caveat.

## Caveats

- n=50 (SE ~7pp); 2 seeds; deltas of <10pp individually within noise --
  the 4/4 sign consistency of the through-cache gains is the robust
  observation, not any single cell.
- em_f1 reward still shifts answer style (terser); anchored enough for
  hotpot, marginal for nq's substring-EM.
- One model (7B), one cache config (q8@8192), 200 steps.
